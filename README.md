**ApexPrompt** is a powerful, unified AI aggregator built to maximize productivity. Instead of jumping between multiple tabs, ApexPrompt allows you to query the world's best AI models (ChatGPT, Claude, and Gemini) simultaneously from a single, beautifully designed dark-mode interface.

🔗 **Live Website:** [www.apexpromt.dev](https://www.apexpromt.dev)

## ✨ Key Features

*   **⚡ Parallel AI Processing:** Send one prompt and get simultaneous answers from ChatGPT, Claude, and Gemini.
*   **⚖️ Dynamic Judge AI:** Automatically evaluates the responses and highlights the most accurate and helpful one.
*   **🔌 Seamless Extension Integration:** Uses custom "Ghost Window" technology via a Chrome Extension to fetch responses without interrupting your workflow.
*   **🔒 100% Secure & Private:** API keys (if used) are stored strictly in your browser's local storage.
*   **💾 Local Session Management:** Automatically saves your chat history locally so you never lose your previous prompts.
*   **🎨 Premium UI/UX:** A stunning, responsive dark theme built for developers and power users.

## 🛠️ How to Use (Installation Guide)

Using ApexPrompt is incredibly simple. Just follow these steps:

### Step 1: Visit the Website
Go to [www.apexpromt.dev](https://www.apexpromt.dev).

### Step 2: Download the Extension
Upon visiting the site for the first time, you will be prompted to download the **ApexPrompt Bridge Extension**. 
1. Click the "Download Extension" button.
2. Extract/Unzip the downloaded `ApexPrompt_Extension.zip` file on your computer.

### Step 3: Install the Extension in Chrome
1. Open Google Chrome and go to `chrome://extensions/`
2. Turn on **Developer mode** (toggle switch in the top right corner).
3. Click on **Load unpacked** and select the unzipped `ApexPrompt_Extension` folder.

### Step 4: Start Prompting!
Go back to [www.apexpromt.dev](https://www.apexpromt.dev), refresh the page, select your preferred AI models, and type your prompt. Watch the magic happen!
